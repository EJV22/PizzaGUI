# PizzaGUI

An interactive Java Swing application that allows users to customize a pizza through a graphical interface!

Features:
- Ingredient selection via GUI buttons
- Real-time UI updates
- Event-driven programming
- Object-oriented structure

Tech Stack:
- Java
- Swing (JFrame, JButton, JLabel)

How to Run:
1. Open project in IDE (IntelliJ / Eclipse)
2. Run main class
